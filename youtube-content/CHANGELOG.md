# CHANGELOG

## 18.10.2026

### Комментарии под постами Telegram
- Новый `scripts/telegram_comments.py`: сбор ВСЕХ комментариев под постом через локальную Telethon-сессию пользователя (Bot API не умеет читать треды). Подкоманды: `status`, `login` (двухфазный: запрос кода → вход с кодом/паролем), `comments --link/--chat/--post [--sentiment]`.
- Ленивый логин: сессия НЕ создаётся при установке навыка — только когда пользователь попросил комментарии под постом, а сессии нет; тогда явно объясняется зачем логин (Bot API, локальный аккаунт, сессия хранится на машине пользователя, у каждого коллеги своя). `--sentiment` считает настроение и однородность тредов тем же лексиконом, что и comment_sentiment.py.

- `bigbro-analyze` встроен в конвейер как обязательный слой для транскрипта: новый `scripts/psych_layer.py` прогоняет транскрипт через три слоя (маркеры → RAG → ONNX-классификатор), вердикты мержатся в метки ⚫ с парами подтипа (`⚫ 🔪🧠` манипуляции/НЛП, `⚫ 📢🧠` пропаганда); при расхождении показываются оба вердикта, при недоступности слоя — тихая деградация к обычным проходам. Транскрипт-only: слой никогда не применяется к сообщению чата.
- Метка ⚫ получила подтипы в таймлайне: `⚫ 🔪🧠` — психологические манипуляции и НЛП-приёмы (встроенные пресуппозиции, якорение, раппорт), `⚫ 📢🧠` — пропаганда (кампания/нарратив, вещание на массы, «мы vs они»). Формат: `⚫ <пара> [MM:SS–MM:SS] …`; ⚫ без пары — незавершённая метка. Обновлены таблица тегов, манипуляционный проход (3b) и правила ⚫ в SKILL.md.
