### Обогащение описаний устройств (70/70) через открытый поиск
- По всем 70 устройствам прогнан русский запрос `«устройство» приведи примеры` и английский `"en_name" examples` (перевод названий — `psychology/devices_enriched.json`, поле `en_name`). Google AI-режим недоступен (капча по IP), использованы рабочие бэкенды: поисковый инструмент + Bing/DuckDuckGo через браузер.
- Результат: 210 примеров с указанием источника на каждый, 127 новых фактов, не повторяющих имеющиеся определения (`extra`). Без примеров не осталось ни одного устройства.
- 10 проверенных примеров добавлены в `eval_set.json` с атрибуцией источника; 5 устройств остались без eval-примера (Управление первым впечатлением, Накопительный фрейминг, Эмоциональная нарастающая, Преёмпт-инокуляция, Апелляция к здравому смыслу) — там найдены только определения, без реальной речевой реализации.
- Замер после расширения: исходные 55 примеров — без регресса (32.7% exact / 40% family / 27.3% miss). Новые 10 реальных примеров: exact 0%, family 10%, miss 90% — маркерный слой на живых формулировках слеп, что подтверждает границу слоя: лексически наблюдаемые приёмы ловит маркер, логико-текстовые берут RAG+LLM. Итог по 65 позитивам: 27.7 / 35.4 / 36.9, FP контролей 20%, роутинг подтипа 93.3%.

### Чат-контент
- НЛП-маркерные пакеты: детерминированные паттерны на якорение/внушение/Дилтса (семьи «НЛП: …», «Фокусы языка: …»), имя устройства в candidates маркера; роутинг подтипов в psych_layer учитывает их (🔪🧠 для НЛП-семейств). Замер на eval_set.json (55+15): exact-device recall 32.7%, family 40%, контрольный FP 20%, subtype-роутинг 92.9%; логико-статистические приёмы лексически ненаблюдаемы (слой RAG+LLM) — зафиксировано честно.
- Файлы и длинные посты больше не анализируются сразу: сначала вопрос-подтверждение формой с двумя кнопками — «Показать Большому Брату?» (ru) / «Big Bro analyze?» (en) + кнопки «Показать» / «Отмена». «Показать» → полный разбор (psych_layer + разметка); «Отмена» → ничего не делать.
- Навык применяется к пользовательскому контенту из чата: скинутый текстовый файл (.txt/.md) читается и разбирается как пост; длинный пересланный/вставленный пост из другой группы (≥2 абзацев). Полный прогон трёх слоёв одним вызовом: `../youtube-content/scripts/psych_layer.py --file <path>` (маркеры → классификация по абзацам → retrieval одним JSON); метки классификатора мержатся в ⚫ с парами подтипа (пропаганда → 📢🧠, манипуляции/НЛП → 🔪🧠), расхождение — оба вердикта.
- ⚫ в таблице тегов и правилах получил пары подтипа: `⚫ 🔪🧠` (манипуляции, НЛП) и `⚫ 📢🧠` (пропаганда); ⚫ без пары — незавершённая метка. Словарь общий с youtube-content.
